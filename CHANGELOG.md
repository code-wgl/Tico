# Tico changelog

## 1.0.11 — 2026-11-07

- First Tico release based on the open-source Tic project, with Tico branding and blue icons.
- Floating desktop notes and tasks, Markdown editing, and optional MCP integration.
- Universal macOS package for Apple Silicon and Intel, with ZIP and DMG downloads.
- Automated builds, tests, package integrity checks, and GitHub Pages deployment.

The package is ad-hoc signed and is not notarized by Apple. Upstream automatic updates and folder sync are not available in this release. GitHub CI tests pass; SwiftLint reports existing violations.

Earlier upstream history remains available in the Git commit history and the [Tic project](https://github.com/kasvith/tic).
