01 / FLOATING NOTES

One note.
A clear start.

Each note lives in its own window. Move, resize, pin it above other windows, or show it on all Spaces. Double-click to roll it up, expand it when needed, and snap it near the bottom of your screen.

  • Select multiple notes, move them together, and arrange their layout
  • Restore window positions, sizes, and open states
  • Create and find notes from the menu bar

02 / TASKS & MARKDOWN

Think freely.
Act clearly.

Write in Markdown, make checklists, and break big tasks into smaller steps. Drag to reorder and nest, then complete, hide, or move finished tasks to the bottom.

GOOD TO KNOW

Good to know.

Is Tico free?

Yes. Tico is free and open source under the MIT license. Explore the code, report an issue, or contribute.

Where are my notes stored?

The stable app stores data locally on your Mac using Tic’s existing app identity and data directory. The development app uses a separate directory. Export backups regularly.

Which Macs are supported?

The current release requires macOS 14 or later and supports Apple Silicon and Intel. See the release page for details.

Does it support sync and automatic updates?

Folder sync and automatic updates from upstream are not enabled in 1.0.11. Back up manually and check GitHub Releases for new versions.

How do I back up or migrate?

Export Markdown, plain text, or JSON. JSON is better suited to complete backups; plain text does not include images or appearance.

How do I connect an AI client?

Enable MCP in the app settings and follow the instructions for a compatible client. MCP is off by default.
